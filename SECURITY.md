# Security

This is a local demo. It is not a production service.

## Report a vulnerability

Do not open a public GitHub issue for security reports.

Email **info@opendream.co.th** with:

- a short description of the issue
- steps to reproduce, if you have them
- the affected commit or tag, if known

We will acknowledge the report and say what we plan to do.

## Please do not

- Include real user chat logs or personal data in a report. This project uses synthetic test data only.
- Scan or attack any deployment that is not yours.
