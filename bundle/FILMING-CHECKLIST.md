# How to film (one page)

**Day before (with internet)**
1. Unzip, run `./start.sh` (or double-click `start.command`). Wait for "verified (sha256)" and Chrome opening.
2. Use your **normal Chrome profile, not Incognito or Guest** (Incognito drops the model cache and has a small storage quota).
3. Wait until the pill shows **🔒 โมเดลในเครื่อง: Qwen3-… · ออฟไลน์**. This first load fills Chrome's cache.
4. Reload once: the pill should go to ready in seconds, with no download.
5. Run all six screens below once as a rehearsal.

**On the day**
1. Plug in power. Do-not-disturb on, notifications off, close other tabs/apps. Bookmarks bar hidden.
2. Start `./start.command`. Wait for the ready pill.
3. **Turn Wi-Fi off** (after the pill says ready). Optional proof shot: DevTools → Network, reload, run the flow: only `127.0.0.1` rows, none during the chat.
4. Window ~ phone width (or DevTools device mode, iPhone 12/13), zoom 100%. Hide DevTools for the main shots.
5. Clear between takes with **ลบแชท** (erase) or by reloading. Nothing is stored, so a reload is a clean slate.

**Screens to show (synthetic text only, never real cases)**
1. **Start**: three promises (not medical advice · on device, nothing sent · 15+), age band, **ออกด่วน** quick exit.
2. **S1 flow**: type "ประจำเดือนมาช้าไปสองอาทิตย์ กลัวท้อง ไม่กล้าบอกใคร" → suggestions (1663 first, open-now badge) → summary → edit one line → approve.
3. **Handoff**: the **DEMO — ยังไม่ได้ส่งอะไรเลย / nothing was sent** banner. Always keep this in frame.
4. **Crisis**: type "ช่วงนี้ไม่อยากมีชีวิตอยู่แล้ว" → crisis screen, 1323 first, tap-to-call. Optional: S4 consent / S5 mental health.
5. **Quick exit**: press ออกด่วน → neutral page; no trace of the text.
6. **Model pill**: close-up of "โมเดลในเครื่อง … ออฟไลน์" with Wi-Fi visibly off in the menu bar.

**Don't**: show the URL bar with query switches, type real names or phone numbers, or film with Wi-Fi on while claiming offline.
If the model fails on camera, the app keeps working on rules; the pill then reads "ใช้กฎพื้นฐาน". Re-take or film the rules version.
